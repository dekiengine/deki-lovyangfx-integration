deki-lovyangfx-integration

LovyanGFX 1.2.19를 통한 임베디드 디스플레이와 터치. 일반적인 SPI/병렬 TFT와 FT6336U 정전식 터치 패널을 구동합니다.

저장소: github.com/dekiengine/deki-lovyangfx-integration · 최신 릴리스: 0.20.0 · 엔진 0.19.0 이상 필요 · 의존: deki-i2c, deki-input

DekiEditor --packages-add deki-lovyangfx-integration <project> 또는 패키지 관리자로 설치합니다. 엔진 자체의 컴포넌트와 C++ API는 Deki 문서에 있습니다.

에디터에는 LovyanGFX Integration(으)로 표시됩니다.

컴포넌트

컴포넌트 카테고리 설명
LGFXDisplayPanel LovyanGFX LovyanGFX를 통해 SPI, QSPI 또는 병렬 버스로 디스플레이 패널(ILI9341, ST7789, GC9A01, RM67162 AMOLED 등)을 구동합니다.
LGFXTouchPanel LovyanGFX LovyanGFX를 통해 터치 컨트롤러(FT5x06, GT911, CST816S, XPT2046)를 읽습니다.

변경 내역

변경 내역은 영어로 되어 있습니다.

0.20.0

Added

  • ST7789TDeck panel type: the LilyGO T-Deck's ST7789 module, started with the voltages and gamma of LilyGO's own setup for it, and VCOM 0x19. LovyanGFX's ST7789 init leaves this panel with a fading ghost of what it showed before. It takes rgbOrder on.
  • Big-endian RGB565 (DEKI_RGB565_BIG_ENDIAN): an RGB565 frame is swapped only when the panel takes the other byte order than the build (swapBytes differs from Deki::kRGB565BigEndian), so a big-endian build sends frames to an SPI panel without a swap. asyncPresent works in such a build.

Fixed

  • With a UI overlay showing, a frame the engine draws straight into (direct or passthrough) was byte-swapped in place for the panel, so the next frame blended against swapped pixels. It goes through the staging bands, which swap while copying, as it does without an overlay.
  • A PSRAM display buffer was flushed from the cache before the byte swap wrote to it; it is flushed after.

0.19.0

Changed

  • minEngine 0.19.0: built against engine 0.19.0, whose component metadata records the package each class is in. A build of this package from before does not load and is rebuilt.

Added

  • Japanese, Simplified Chinese and Korean: editor/lang/ja.json, zh.json and ko.json translate the names, tooltips and enum values this package's components show in the Inspector.
