deki-lovyangfx-integration

通过 LovyanGFX 1.2.19 实现嵌入式显示和触摸。驱动常见的 SPI/并口 TFT 屏和 FT6336U 电容触摸面板。

仓库：github.com/dekiengine/deki-lovyangfx-integration · 最新版本：0.19.0 · 需要引擎 0.19.0 或更高版本 · 依赖：deki-i2c, deki-input

使用 DekiEditor --packages-add deki-lovyangfx-integration <project> 或通过包管理器安装。引擎自身的组件和 C++ API 见 Deki 文档。

在编辑器中显示为 **LovyanGFX Integration**。

组件

组件 类别 说明
LGFXDisplayPanel LovyanGFX 通过 LovyanGFX，经由 SPI、QSPI 或并行总线驱动显示面板（ILI9341、ST7789、GC9A01、RM67162 AMOLED 等）。
LGFXTouchPanel LovyanGFX 通过 LovyanGFX 读取触摸控制器（FT5x06、GT911、CST816S、XPT2046）。

功能开关

可以从构建中去掉的部分。带有 define 的功能通过该 define 开关，其余的随其组件一起被剥离。

功能 define 默认值
Display Panel DEKI_FEATURE_LGFX_DISPLAY_PANEL 开
Touch Panel DEKI_FEATURE_LGFX_TOUCH_PANEL 开

更新日志

更新日志为英文。

0.19.0

Changed

  • minEngine 0.19.0: built against engine 0.19.0, whose component metadata records the package each class is in. A build of this package from before does not load and is rebuilt.

Added

  • Japanese, Simplified Chinese and Korean: editor/lang/ja.json, zh.json and ko.json translate the names, tooltips and enum values this package's components show in the Inspector.

0.18.2

Added

  • asyncPresent on the display panel: a frame is sent from the other core while the next is drawn, through two staging buffers in PSRAM. Drawing and sending each fit in a 60 Hz frame on a LilyGO T-Deck, one after the other they did not. On ESP32 with two cores; off by default.

Changed

  • A frame goes to the panel by DMA, in bands within one transaction: each band is converted while the one before is being sent. Each band used to be fed to the SPI FIFO by the CPU and waited for before the next was converted, the conversion and the transfer one after the other.

Fixed

  • An I2C touch panel no longer shares the display's bus. Shared, each touch read ended the display's SPI transaction, which broke a frame being sent from the other core.
  • The backlight starts at full brightness (blBrightness, 255 by default), as it is after waking from sleep. It started at LovyanGFX's 127, a 1.2 kHz PWM wave, and a backlight driver that dims by counting pulses, as the LilyGO T-Deck's does, read every cycle of it as a step down and flickered.
  • The touch panel's bounds group was labelled "Touch Panel DekiParticles::Bounds". The bounds' tooltips say they run along the panel before the display is rotated, and offsetRotation's that it is added to the display rotation (it is not the display rotation).
